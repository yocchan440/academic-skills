Overleaf と LaTeX

配布テンプレートで卒業論文を書く

  • Overleaf にテンプレートを取り込み、正しい設定でコンパイルできる
  • 見出し・段落・図表・数式・引用を LaTeX で書ける
  • よくあるエラーを自分で読み解いて直せる

操作：← → / Space でページ送り　O キーでスライド一覧

なぜ LaTeX で書くのかWhy LaTeX?

LaTeX は「見た目を作る」道具ではない。「これは何か」を書くと、体裁は自動で付いてくる仕組みである。

自動でやってくれること
  • 章・節の番号（入れ替えても振り直される）
  • 目次・図目次・表目次
  • 図表の番号と配置
  • 本文からの相互参照（図 3、表 2、式 (1)）
  • 参考文献の番号と並び順、書式の統一
  • 数式の組版

つまり トピック 02・11・12 で「手で書くな」と言った番号類は、すべて LaTeX の仕事である。

Overleaf を使う ブラウザだけで動く LaTeX 環境。インストール不要で、 保存・履歴・共有が自動。指導教員と同じ画面を見ながら相談できる。
最初の 30 分だけ我慢する 最初はエラーが出て進まない。それは全員が通る道である。 このトピックの内容を一度通して読めば、卒論を書き切るのに必要な範囲はほぼ足りる。

Overleaf での最初の 3 手順Setup

ここを間違えると必ずコンパイルに失敗する。最初に一度だけ設定する。

  1. プロジェクトを作る
    Overleaf の New Project → Upload Project に、配布された sotsuron2025je.zip をそのままドラッグする。展開は不要。
  2. コンパイラを LuaLaTeX にする
    左上の Menu → Compiler を LuaLaTeX に変更する。テンプレートは jlreq と luatexja を使っているため、pdfLaTeX では通らない。
  3. メイン文書を 00_MAIN.tex にする
    同じ Menu の Main document で 00_MAIN.tex を選ぶ。 ここを間違えると、章の一部しか出力されない。
確認 Recompile を押して、表紙・内容梗概・目次・各章が出た PDF が表示されれば成功である。 初回は数十秒かかることがある。
触らないファイル latexmkrc は参考文献の処理方法（pBibTeX）を指定している設定ファイルである。編集しない。

相互参照 \label と \refCross references

番号を手で書かない。名前を付けて、名前で呼ぶ。

名前を付ける／呼ぶ

% 図に名前を付ける（caption の直後に置く）
\caption{提案手法のシステム構成}
\label{fig:system}

% 本文から呼ぶ
提案手法の構成を図\ref{fig:system}に示す．
実験環境を表\ref{tbl:env}に示す．
適合率は式(\ref{eq:precision})で定義される．
詳細は\ref{sec:dataset}節で述べる．

接頭辞で種類が分かるようにする

対象接頭辞例
章chap:chap:introduction
節sec:sec:dataset
図fig:fig:system
表tbl:tbl:env
式eq:eq:precision
プログラムlst:lst:extract
参照が ?? になるとき ・もう一度コンパイルする（番号は 2 回目のコンパイルで確定する。Overleaf は通常自動で処理する）
・それでも直らなければ \label のつづり間違い。大文字・小文字も区別される
・\label を \caption より前に置くと、番号がずれる

図の入れ方Figures

図題は下。\caption を \includegraphics の後ろに書く。

figure 環境

\begin{figure}[tbp]
  \centering
  \includegraphics[width=10cm]{fig/system.pdf}
  \caption{提案手法のシステム構成}
  \label{fig:system}
\end{figure}

画像は Overleaf の左のファイル一覧で Upload する。 fig フォルダを作って入れておくと整理しやすい。 グラフ・構成図は PDF か SVG で（トピック 11）。

[tbp] とは 図を置いてよい場所の指定。t＝ページ上部、b＝下部、p＝図だけのページ、h＝書いた位置。
[h] を多用しない。LaTeX が置き場所を探せなくなり、図が全部末尾に飛ぶ。
図は必ず本文で引用して説明する \ref{fig:system} で本文から引用し、何を表しているかを文章で述べる。 貼っただけの図は載せてはいけない。

表の入れ方Tables

表題は上。\caption を tabular の前に書く。罫線は booktabs の 3 本。

table 環境

  \label{tbl:compare}

    田中ら\cite{tanaka2022} & 0.91 & 0.71 \\
    \textbf{提案手法} & 0.94 & \textbf{0.93} \\

\end{table}

数式とソースコードEquations and listings

数式は equation、ソースコードは lstlisting。どちらも番号と参照が自動。

文中と別行立て

% 文中の数式は $ ... $ で囲む
適合率 $P$ と再現率 $R$ を用いる．

% 別行立て（番号が付く）
\begin{equation}
  F = \frac{2PR}{P+R}
  \label{eq:fmeasure}
\end{equation}

F 値は式(\ref{eq:fmeasure})で定義される．

変数は必ず $ $ の中に。地の文に _ や ^ を書くとエラーになる。

lstlisting（設定済み）

\begin{figure}[tbp]
\begin{lstlisting}
Contact: mailto:security@example.jp
Expires: 2026-04-01T08:59:59.999Z
Preferred-Languages: ja, en
\end{lstlisting}
\caption{security.txt の記述例}
\label{lst:securitytxt}
\end{figure}
注意 lstlisting の中では LaTeX のコマンドはそのまま文字として出力される。
プログラム全文を貼らない。本文で説明する数行だけを載せ、 全体は付録か公開リポジトリへ。

引用と参考文献Citations

文献は 22_References.bib に貯める。番号・並び順・書式はすべて自動で統一される。

Google Scholar などから取得して貼る

@article{tanaka2022,
  author  = {田中太郎 and 山田花子},
  title   = {{URL 特徴量に基づくフィッシング検知}},
  journal = {情報処理学会論文誌},
  volume  = {63}, number  = {9},
  pages   = {1--10},
  year    = {2022}
}

複数まとめる場合は\cite{ma2009,tanaka2022}．

・{{ }} で囲んだ部分は大文字・小文字がそのまま保たれる

文献番号は句点の前に置く。書き方の詳細は トピック 12。

執筆を楽にするコツPractical tips

半年つきあう道具である。最初に習慣を作っておく。

  • 1 文ごとに改行する
    出力は変わらない。直したい文にすぐ辿り着ける
  • こまめに Recompile する
    1 節書くごと。まとめて書くとエラーの原因が特定できない
  • 通る状態を保つ
    書きかけは % でコメントアウトしておく
  • メモは % で残す
    % TODO: ここに実験結果の表を入れる
Overleaf の機能を使う ・History（履歴）… いつでも過去の版に戻せる。バックアップは自動
・Share … 指導教員に読み取り／編集権限を渡せる
・Menu → Download → PDF … 提出用の PDF を取得
・Menu → Download → Source … 一式を zip で保存（学期末に手元にも残す）
提出前に ・Recompile from scratch を一度実行し、警告が残っていないか確認する
・目次・図目次・表目次のページ番号が本文と合っているか
・?? や [?] が残っていないか

このトピックのまとめSummary

LaTeX は「書くこと」に集中させてくれる道具である。番号と体裁は任せる。

  • Overleaf の設定は Compiler = LuaLaTeX、Main document = 00_MAIN.tex
  • \chapter は 00_MAIN.tex。各章は \section から書く
  • 段落の区切りは空行。\\ で段落を作らない
  • 1 文 1 行で書くと後が楽
  • 番号は \label と \ref で呼ぶ。手で書かない
  • 図は figure、\caption は後ろ
  • 表は table、\caption は前。罫線は booktabs
  • 文献は 22_References.bib ＋ \cite
  • % & _ # はエスケープが必要
  • エラーは最初の 1 件を読む
最初にやること 配布された sotsuron2025je.zip を Overleaf に上げて、 表紙の題目と氏名を自分のものに書き換えてコンパイルしてみる。 PDF が出れば、環境の準備は終わりである。
