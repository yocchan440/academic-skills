当日の進行

入れ替えは迅速に。準備の時間は用意されていない

  • 発表者の入れ替えを迅速に行える
  • 機材の確認事項を把握している
  • スライドショーをキーで操作できる
  • トラブル時に落ち着いて対応できる

操作：← → / Space でページ送り　O キーでスライド一覧

発表者の入れ替えは迅速にSwap quickly

プログラムを見れば分かるが、発表者の入れ替え時間は準備されていない。

次に発表する人がやること
  1. 前の方で待機しておく
    自分の番の 1 つ前の発表が始まったら、前方の席へ移動する
  2. 座長が題目と発表者の紹介を終えたら、すぐに発表できるように素早く準備する
  3. PC を接続する場合は、前の発表中にケーブルの位置を確認しておく
やってはいけない 名前を呼ばれてからのらりくらりと現れる。 席を立ち、鞄を探り、PC を出し、ケーブルを探す。 この 1 分は、誰かの発表時間から奪われている。
スムーズな入れ替えの手順
  1. 前の発表が始まったら前方へ移動
  2. PC を開き、スライドを開いた状態にしておく
  3. 前の発表者の質疑が終わったら、演台へ
  4. ケーブルを挿し、投影を確認
  5. スライドショーを開始し、表紙を出す
  6. 座長の紹介を受けて、すぐに話し始める

ここまで 30 秒以内。練習しておけばできる。

機材の確認Equipment

当日の朝、実際に投影して確認する。事故のほとんどはここで防げる。

確認することやること
接続端子HDMI か VGA か、USB-C か。変換アダプタが必要かを事前に確認する
投影の確認実際に映して、文字と色が読めるかを後ろの席から見る
画面比率16:9 か 4:3 か。比率が違うと、左右が切れるか余白が出る
フォント会場 PC を使う場合、フォントが置き換わっていないか（トピック 05）
発表者ツール使えるか。使えない場合に備えて、手元のメモを紙で持つ
スライド送りPC のキー操作か、リモコンか。リモコンなら動作確認
音声動画や音を使うなら、必ず事前に確認
電源PC の電源アダプタを持参。スリープ・スクリーンセーバを切る
必ず PDF 版も持っていく USB メモリとクラウドの両方に、PowerPoint 版と PDF 版を置いておく。 PC が動かなくても、PDF なら会場 PC で開ける。

スライドショーの基本操作Keys

発表中に右クリックやメニュー操作をすると、その画面が聴衆に見える。キーで済ませる。

やりたいことキー補足
最初から開始F5開始前の最終確認にも使える
今のスライドから開始Shift + F5編集中のスライドから始める。途中だけ確認したいとき
次へ進む→送り戻しは矢印キーに統一する（↓ でも進む）
前へ戻る←（↑ でも戻る）
指定のスライドへ移動番号 + Enter例：10Enter で 10 枚目。予備スライドへ飛ぶときに使う
スライド一覧を表示G質疑で、質問に合うスライドを探して選ぶのに便利（Ctrl + - でも可）
レーザーポインターCtrl + Lマウスカーソルがレーザーポインターになる。注目させたい箇所を指す
スライドショーを終了Esc質疑中は終了しない（前のスライドの注意を参照）
質疑のときは 質問を受けたら G で一覧を出し、該当スライドを選ぶ。 番号を覚えているなら、番号 + Enter のほうが速い。

発表者ツールが投影側に出てしまったときSwap displays

聴衆の前にノートやタイマーが映る。慌てず、その場で入れ替える。

A　発表中にすぐ直す
  1. 発表者ツール画面の左上にある ［表示設定］（「…」）をクリック
  2. ［発表者ツールとスライドショーを切り替える］を選ぶ
  3. 発表者ツールが手元、スライドが投影側に入れ替わる

スライドショーを終了せずに直せる。

B　始める前に設定しておく
  1. Win + P で ［拡張］を選ぶ（［複製］では発表者ツールは使えない）
  2. PowerPoint の［スライド ショー］タブを開く
  3. ［発表者ツールを使用する］にチェックを入れる
  4. ［モニター］で、スライドを映す側を選ぶ
［モニター］の選択意味
自動PowerPoint が決める。入れ替わることがある
プライマリ モニターWindows が「メイン」としているディスプレイ（通常は PC 本体の画面）にスライドを出す
セカンダリ モニターもう一方（通常はプロジェクタ）にスライドを出す
それでも直らないとき Windows の［設定］→［システム］→［ディスプレイ］で、映したい側を選び ［これをメイン ディスプレイにする］にチェックを入れると、プライマリとセカンダリが入れ替わる。 会場では必ず本番前に試す。

Mac で発表する場合の注意Mac notes

考え方は Windows と同じ。キーと設定の場所が違う。自分の Mac を持ち込むなら確認しておく。

項目Mac の場合（Microsoft 公式サポートに基づく）
最初から開始⌘ + Shift + Return
今のスライドから開始⌘ + Return
発表者ツールで開始Option + Return（手元にノートとスライド、外部画面にはスライドだけが出る）
送り戻し・終了矢印キーと Esc は Windows と同じ
画面の入れ替え発表者ツール左上のツールバーにある［Swap Displays（ディスプレイの入れ替え）］をクリックする
配置がおかしいときPowerPoint を閉じ、［システム設定］→［ディスプレイ］の配置を見直してから、開き直す
表示が遅れるときApple シリコンの Mac で発表者ツールの表示が遅れる例が報告されている。［デスクトップと Dock］の［ディスプレイごとに個別の操作スペース］をオンにして直った例がある
接続端子多くの Mac は USB-C のみ。HDMI・VGA の変換アダプタを自分で持参する
Mac は必ず本番前に試す メニュー名や挙動は macOS と PowerPoint のバージョンで変わる。 会場のプロジェクタに実際に接続して、発表者ツールの位置まで確認する。 PDF 版も必ず持っていく。

出典：Microsoft サポート「Use keyboard shortcuts to deliver PowerPoint presentations」ほか、 Apple コミュニティの投稿。

ハイブリッド発表：Teams・Zoom で共有するHybrid

会場とオンラインの両方に見せる。共有の仕方で、発表者ツールが見えるかどうかが決まる。

Teams
  • ［コンテンツの共有］から PowerPoint のファイルを選ぶ（PowerPoint Live）
  • 発表者には発表者ツール、参加者にはスライドだけが表示される
  • PowerPoint のウィンドウを画面共有すると、発表者ツールが映ることがある
Zoom
  • モニターが 2 つ：スライドショーを出している側のモニターを共有。発表者ツールは手元に残る
  • モニターが 1 つ：スライドショーをウィンドウ表示にして、そのウィンドウだけを共有する。チャットなどの操作も使える
  • 共有された画面が逆なら、［Swap Displays］で入れ替える
共通の注意 ・動画や音を使うなら、共有時にコンピューターの音声を共有する設定をオンにする
・共有範囲を誤ると無関係な画面や通知が相手に見える。必要なウィンドウだけを選ぶ
・共有を始める前に通知を切る。共有開始後に、参加者の画面で映り方を確認する
・会場の画面とオンラインの映りは別物。事前に接続テストをして、操作担当や座長と手順を決めておく

出典：Zoom「Screen sharing a PowerPoint presentation」、 窓の杜の Teams 解説記事、 Microsoft のコラム。 画面や名称は更新で変わるため、最新の操作は各サービスの公式ヘルプで確認する。

発表が終わったらAfter you finish

発表の終わり方と、そのあとスクリーンに何を出すかを決めておく。

  1. まとめスライドを表示したまま終える
    「以上で発表を終わります。ありがとうございました。」
  2. スライドショーは終了しない
    質疑応答の間、まとめスライドを表示しておく。 デスクトップや編集画面を映さない（トピック 08）
  3. 質問に応じてスライドを移動する
    該当スライドや予備スライドへ。必要な情報を提示しながら説明する
  4. 質疑が終わったら、速やかに片づける
    ケーブルを外し、次の発表者に場所を譲る
  5. 指摘をメモに残す
    論文の修正に使える。その日のうちに書き留める
自分の発表が終わっても帰らない 他の人の発表を聞くことも、発表会の一部である。 他人の発表からは、自分の発表の改善点がよく見える。 良かった発表は何が良かったのかを考えると、次に活きる。

トラブルへの備えWhen things go wrong

起きてから考えない。起きたときの行動を決めておく。

トラブルその場の対応事前の備え
PC が映らない会場 PC を借りる。落ち着いて座長に伝えるUSB に PDF を入れて持参
フォントが崩れたそのまま続ける。読めない箇所は口頭で補うPDF 版を使う
スライドが進まないPC 本体のキーで操作するリモコンに頼りきらない
頭が真っ白になったいったん黙る。スライドを見て、次の 1 文を思い出す各スライドの最初の 1 文を決めておく
時間が押している残りの説明を軽くし、まとめまで到達する4 分地点の通過時間を決めておく
ベルが鳴った速やかに終える。まとめは読まない（トピック 10）
言い間違えた「失礼しました、正しくは〜です」と訂正して進む気にしすぎない
共通するのは「落ち着いて続ける」 トラブルそのものより、動揺して発表が崩れるほうが損失が大きい。 機材トラブルは、聴衆はあなたのせいだと思っていない。

当日の持ち物What to bring

前日に用意しておく。当日の朝に探さない。

必須
  • ノート PC と電源アダプタ
  • 変換アダプタ（HDMI・VGA・USB-C）
  • USB メモリ（pptx と PDF の両方）
  • クラウドにも同じファイルを置く
  • 腕時計（演台に置く）
あると安心
  • 予備スライドの番号一覧（紙）
  • 各スライドの最初の 1 文のメモ（紙）
  • レーザーポインタ（使い慣れたもの）
  • 飲み物（発表直前に一口）
  • 印刷したスライド（自分用）
前日にやっておくこと ・ファイルを最終版に確定させ、USB とクラウドに置く
・PC のスリープ・スクリーンセーバ・通知を切る
・デスクトップを整理する（映る可能性がある）
・発表順と自分の時刻を確認する　・十分に寝る
