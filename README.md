# Academic Skills — 読む・書く・発表する

情報系の学生が研究に取り組むための教材 3 部作です。
先行研究を**読み**、自分の成果を論文に**書き**、それを人前で**発表する** —
この 3 つは、同じ「型」（IMRAD）を別の角度から使う技能です。

**公開先 → <https://www.kkzk-lab.com/academic-skills>**

## 収録内容

| | 教材 | 内容 |
| --- | --- | --- |
| STEP 1 | [**論文の読み方**](reading/) | 推理せず、書いてあることを書いてあるとおりに読む。IMRAD の構造と定型表現、情報セキュリティ分野に特有の読み方。 |
| STEP 2 | [**卒業論文の書き方**](writing/) | 「作文」でも「レポート」でもない文章を書く。章ごとの書き方、日本語表記、図表と引用、Overleaf と LaTeX。 |
| STEP 3 | [**卒研発表の仕方**](presentation/) | 短い時間で、専門外の聴衆に成果を伝えきる。聴衆が「？」と思わないように進めること、時間の無駄をなくすこと。 |

各教材は **説明資料（HTML スライド 16 トピック）＋ ツール 2 点** で構成されています。

## 使い方

公開先の URL を開くか、リポジトリを取得して `index.html` をブラウザで開いてください。
ビルドもインターネット接続も不要です（Web フォントの取得にのみ使用します）。

説明資料は HTML スライドです。

- `←` `→` / `Space` … ページ送り
- `O` … スライド一覧
- `Home` / `End` … 先頭・末尾へ
- 右上の「印刷」… 1 枚 1 ページで PDF 化
- URL 末尾の `#5` がスライド番号（特定のスライドを共有できます）

## 設計方針

- **カラーユニバーサルデザイン**：配色は Okabe–Ito の推奨 8 色を基準にし、色だけで意味を区別せず記号・ラベル・線種を併用。グレースケール印刷でも判別できます
- **ユニバーサルデザインフォント**：BIZ UD ゴシック／BIZ UD 明朝（未導入の環境では OS 同梱の UD フォントや游書体で代替）
- ライトテーマ固定、文字と背景のコントラストを確保

## 構成

```
index.html          3 部作のランディングページ
assets/             ランディングページ用のスタイル
reading/            論文の読み方
writing/            卒業論文の書き方
presentation/       卒研発表の仕方
  ├ index.html        その教材のトップ
  ├ slides/           HTML スライド（01〜16）
  ├ assets/           スタイルとスクリプト
  └ （ツール HTML）
```

各教材は自己完結しており、フォルダ単体でも動作します。
そのため `assets/base.css`・`slides.css`・`slides.js` は各教材に同じものが置かれています。

## 注意

学科・研究室が定める要領がある場合は、そちらを優先してください。

作成の元にした指導資料・卒論テンプレート（`ref/`）は、本リポジトリには含めていません。
