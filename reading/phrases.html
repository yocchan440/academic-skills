論文定型表現の一覧

論文は決まった表現で書かれています。表現を覚えれば、その文が論文の中で果たしている役割が、 読む前から分かります。印刷して手元に置き、論文を読みながら引いてください。 解説は トピック 11「論文の定型表現」にあります。

A　役割を示す表現（和文）

この表現を見つけたら、そこが論文の骨格です。太字は特に重要。

役割表現

先行研究の紹介〜らは〜を提案している [n]／〜が報告されている [n]／〜については〜が広く研究されている
Gap（欠落）しかし、〜は明らかになっていない／〜については十分に検討されていない／〜を定量的に評価した研究は見当たらない／〜に関する実証的な研究は限定的である／著者の知る限り、〜は報告されていない／この前提は〜の場合には成立しない

C　シグナル表現

著者が「ここを見てほしい」と言っている箇所です。飛ばし読みでも、ここだけは止まります。

合図和文英文
逆接・転換しかし／一方／ところが／これに対し／とはいえHowever / In contrast / Nevertheless / Yet / On the other hand
強調特に／特筆すべきは／重要なことに／注目すべき点はImportantly / Crucially / In particular / Notably / Specifically
主張本研究では〜と考える／〜であると主張するWe argue that / We claim that / We believe that
限定・注意ただし／なお／〜に限り／〜の場合に限ってNote that / only when / unless / provided that
帰結したがって／以上より／その結果／ゆえにTherefore / Thus / Consequently / As a result / Hence
意外性意外にも／予想に反して／興味深いことにSurprisingly / Interestingly / Counterintuitively / Unexpectedly
例示たとえば／具体的には／一例としてFor example / For instance / Specifically
追加また／さらに／加えてMoreover / Furthermore / In addition
最強の 2 語 和文の「しかし」と英文の “However”。論文の主張の転換点は、ほぼこの語の後にあります。 PDF の検索機能で “However” を検索するだけでも、骨格が見えます。

D　主張の強さを示す表現

著者は、言い切れる範囲でしか言い切りません。その加減が語尾と助動詞に出ます。

強さ和文英文読み方
強〜である／〜を示した... is ... / We show that ...事実として主張している。著者が責任を持つ
↑〜が確認された／〜が明らかになったWe observe / We confirm that ...実験・調査で確かめた事実
中〜と考えられる／〜と推察される... is likely / appears to / tends to ...著者の解釈。事実ではない
↓〜が示唆されるThese findings suggest that ...傾向が見えた程度。断定していない
弱〜の可能性がある／〜かもしれない... may / might / could ...仮説。根拠は弱い
—〜が期待される／〜が望まれるWe expect / We hope that ...著者の願望。検証されていない
引用するときに効いてきます 原文が 〜と考えられる／suggest なら、引用も解釈として引きます。
✗ 文献 [5] によれば、フィードバックが行動変容の要因である。
✓ 文献 [5] は、フィードバックが行動変容の要因であると推察している。
解釈を事実に格上げして引用するのは誤引用です。
特に注意する 2 つ ・「有意差は認められなかった」≠「差はない」（この実験では検出できなかった、という意味）
・相関 ≠ 因果（「A が増えると B が減る」は因果関係の主張ではない）

F　情報セキュリティ分野の頻出用語

知っていれば、読む速度が上がります。日本語訳は 1 つに決めて使ってください。

英語意味
threat model脅威モデル。想定する攻撃者の定義。セキュリティ論文で最も重要な節
adversary攻撃者
attack surface攻撃対象面。攻撃されうる箇所の総体
adaptive attack適応的攻撃。防御手法の詳細を知ったうえでの攻撃
evasion回避。検知をすり抜けること
false positive / negative偽陽性（誤検知）／偽陰性（見逃し）
ground truth正解データ
baseline比較対象とする既存手法
ablation study構成要素を外して、その寄与を測る実験
in the wild実世界で。実際に観測された
zero-day未知・未対策の脆弱性
PoC (Proof of Concept)実証コード。攻撃が成立することを示す最小限の実装
responsible disclosure責任ある開示。公表前に開発者へ連絡すること
artifact論文に付随する実装・データ。公開されていれば必ず見る
state of the art最先端の手法。比較対象としてよく使われる
To the best of our knowledge著者の知る限り。Gap の主張とセットで出る
Without loss of generality一般性を失うことなく
