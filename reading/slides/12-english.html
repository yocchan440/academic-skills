英語論文の読み方

英語が苦手でも読める。読み方が違うだけ

  • Abstract と Introduction を確実に読み切れる
  • 主語と動詞を押さえて意味を取る方法を使える
  • 翻訳ツールを正しく併用できる

操作：← → / Space でページ送り　O キーでスライド一覧

Abstract と Introduction は全訳するTranslate these two

ここだけは逃げない。翻訳ツールや辞書を駆使してでも読む。

Abstract を全訳する理由

何が書かれている論文なのかを把握するため。 ここを誤解すると、以降の何十ページが無駄になる。

分量は 150〜250 語。15 分もあれば訳せる。

Introduction を全訳する理由

論文のストーリーと成果が書かれているため。 Gap・目的・貢献がここにある。分量は 1〜2 ページだが、 この論文を読むかどうかの最終判断はここでできる。

残りの章は全訳しない Method・Results は必要な箇所だけ。 図表・数式・条件の記述は、英語力よりも 何を探しているかが決まっているかで読めるかどうかが決まる （トピック 02）。
定型表現が効く Abstract と Introduction は、定型表現の密度がいちばん高い場所である。 トピック 11 の 20 個を覚えていれば、 訳す量は半分以下になる。

英語が苦手な人向けの読み方If English is hard for you

文学を読むのではない。情報を取り出すために読む。

  1. 主語と動詞を理解する
    動詞が分かれば、何を言いたいかの想像がつきやすい
  2. わからない単語はどんどん飛ばす
    辞書にない固有名詞はそのままにしておく。細かい表現が分からなくても気にしない
  3. 文として読まずに、単語で読む
    きれいな日本語に訳す必要はない。意味が取れればよい
  4. 重要なことは文の前方に書いてある
    英語は主語と動詞が前に固まっている。文の後方は修飾であることが多い
ただし後方を完全に無視しない 文の後方には only when ...、under the assumption that ... など、 主張を限定する条件が置かれることがある。 主張の文だけは、最後まで読む（トピック 01）。

実際に分解してみるParsing in practice

主語（S）・動詞（V）・目的語（O）を押さえ、残りは修飾として扱う。

S 主語 V 動詞 O 目的語 修飾（後回し）

In this paper, we propose a novel detection method that does not rely on lexical features of URLs, which are known to be ineffective against shortened URLs.

SVO だけ読む：「我々は、新しい検知手法を提案する」
修飾を足す：「URL の語彙的特徴量に依存しない」「（それは）短縮 URL に有効でないと知られている」
→ 読めた。lexical が分からなくても、「URL の何かに依存しない手法」までは取れる。

Our evaluation on 12,400 samples shows that the F1 score improves from 0.71 to 0.93 for shortened URLs.

SVO：「我々の評価は、F 値が 0.71 から 0.93 に改善することを示す」
修飾：「12,400 検体での」「短縮 URL について」
→ 核心の数値と、その条件が両方取れた。

専門用語と論文特有の言い回しJargon

辞書を引いても出てこない言葉がある。それは英語の問題ではない。

一般的に使われない専門用語 同じ分野の論文には、同じ専門用語が繰り返し出現する。 最初の 2〜3 本で用語集を作ってしまえば、以降は楽になる。

例：adversary（攻撃者）、ground truth（正解データ）、 baseline（比較対象手法）、ablation study（要素を外して寄与を見る実験）、 threat model（脅威モデル）

一般的に使われない論文特有の言い回し 定型的な言い回しなので、慣れれば楽に読める。

To the best of our knowledge（著者の知る限り）、 Without loss of generality（一般性を失うことなく）、 We leave ... to future work（今後の課題とする）、 out of scope（対象外）、 state of the art（最先端の手法）

自分の用語ノートを作る 分野の用語は50〜100 語程度で足りることが多い。 出会うたびに書き留めれば、1 か月で読む速度がまったく変わる。

翻訳ツールの使い方Using translation tools

使ってよい。ただし使い方を間違えると誤読する。

正しい使い方
  • 段落単位で訳す（文単位だと文脈が落ちる）
  • 訳を読んで理解したら、原文に戻って確認する
  • 分からない箇所の当たりを付けるために使う
  • 専門用語は訳さずに原語のまま扱う
危ない使い方
  • 訳文だけ読んで原文を見ない
  • 訳文の語尾をそのまま信じる
    → suggest が「示す」と訳されて、解釈が事実になる
  • 否定・限定の訳し落としに気づかない
    → not、only、unless は要確認
  • PDF から直接訳して数式や図表の番号が混ざる
引用する箇所は必ず原文で確認する 自分の卒論で引用する文は、翻訳を経由せずに原文で読む。 主張の強さ（トピック 11）と限定条件は、訳で落ちやすい。

この方法で読めないときはWhen it still doesn't work

正直に言う。英語の問題ではないことが多い。

それは、相当の基礎不足である 主語と動詞を押さえて、定型表現を知っていて、それでも意味が取れない場合、 不足しているのは英語力ではなくその分野の基礎知識である。 研究に必要な基礎は、どこかで身につけておく必要がある。
基礎を埋める順序
  1. 日本語のサーベイ論文・解説記事を読む
  2. 教科書の該当章を読む
  3. 国内の研究会・シンポジウム論文（日本語）を 2〜3 本読む
  4. その参考文献にある英語論文に進む
国内論文から入る利点
  • 日本語なので内容の理解に集中できる
  • 用語の日本語訳と英語が対応付けられる
  • 参考文献にその分野の英語論文が並んでいる
  • 英語が苦手でもとっかかりが得られる

このトピックのまとめSummary

英語論文は、英語の試験ではない。情報を取り出す作業である。

  • Abstract と Introduction は全訳する
  • 残りは必要な箇所だけ
  • 主語と動詞を押さえる
  • 分からない単語は飛ばす。固有名詞はそのまま
  • 重要なことは文の前方にある
  • ただし限定条件は後方にある。主張の文は最後まで読む
  • 翻訳ツールは段落単位で。引用箇所は原文で確認
  • 読めないときは日本語の文献から入る
最初の 1 本を乗り越える 1 本目は 2 日かかる。3 本目には半日になる。10 本目には 1 時間になる。 同じ分野の論文は、同じ用語と同じ表現で書かれているからである。
