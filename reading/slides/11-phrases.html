TOPIC 11

論文の定型表現

論文は、決まった表現で書かれている

  • 定型表現から、その文の役割を即座に判別できる
  • 重要な箇所を示すシグナル表現を拾える
  • 主張の強さを表現から読み取れる

操作：← → / Space でページ送り　O キーでスライド一覧

論文は定型文の集合であるPapers are formulaic

著者は独創的な表現を使わない。だから読者は、表現から役割を判別できる。

なぜ定型的なのか 論文の目的は、内容を誤解なく伝えることである。 表現に凝れば解釈が分かれる。分野の共通語彙で書くことで、 読者は内容の理解だけに集中できる。
読者にとっての利点
  • 「本研究の目的は」を見つけた瞬間、そこが目的文だと分かる
  • 「しかし」で始まる段落は、Gap の段落である可能性が高い
  • 「〜と考えられる」を見た瞬間、事実ではないと分かる
  • 英語でも同じ。定型表現を覚えれば、辞書を引く回数が激減する
この読み方のイメージ

　…が広く用いられている。 Gapしかし、〜については十分に検討されていない。 目的本研究の目的は、〜を明らかにすることである。…

全文を読まなくても、太字の合図だけを拾えば骨格が取れる。 これが、定型表現を覚える最大の見返りである。

シグナル表現：ここが重要という合図Signal phrases

著者が「ここを見てほしい」と言っている箇所。飛ばし読みでも、ここだけは止まる。

和文
合図表現
逆接・転換しかし／一方／ところが／これに対し
強調特に／特筆すべきは／重要なことに／注目すべき点は
主張本研究では〜と考える／〜であると主張する
限定ただし／なお／〜に限り／〜の場合
帰結したがって／以上より／その結果
意外性意外にも／予想に反して
英文
合図表現
逆接・転換However / In contrast / Nevertheless / Yet
強調Importantly / Crucially / In particular / Notably
主張We argue that / We claim that
限定Note that / However, this holds only when ...
帰結Therefore / Thus / Consequently / As a result
意外性Surprisingly / Interestingly / Counterintuitively
最強の 2 語 和文の「しかし」と英文の“However”。 論文の主張の転換点は、ほぼこの語の後にある。検索機能で “However” を検索するだけでも骨格が見える。

主張の強さを表す表現Hedging

著者は、言い切れる範囲でしか言い切らない。その加減が表現に出る。

強さ和文英文読み方
強〜である／〜を示した... is ... / We show that ...事実として主張している
↑〜が確認されたWe observe / We confirm that ...観測した事実
中〜と考えられる... is likely / appears to ...著者の解釈
↓〜が示唆されるThese findings suggest ...傾向。断定していない
弱〜の可能性がある... may / might / could ...仮説
—〜が期待されるWe expect / We hope that ...願望。検証されていない
引用するときに効いてくる ✗ 文献 [5] によれば、フィードバックが行動変容の要因である。
✓ 文献 [5] は、フィードバックが行動変容の要因であると推察している。
— 原文が 〜と考えられる なら、引用も解釈として引く。 事実に格上げして引用するのは誤引用である。

定型表現を使って読むReading by pattern

実際の読み方。表現を拾って、骨格だけを先に組み立てる。

  1. PDF で「しかし」「However」を検索する
    ヒットした箇所の前後を読む。そこに Gap がある
  2. 「本研究の目的は」「In this paper, we」を検索する
    目的文が見つかる。これが論文の憲法
  3. 「その結果」「Our results show」を検索する
    核心の数値が見つかる
  4. 「と考えられる」「suggest」を検索する
    著者の解釈が集まっている。事実と区別して読む
  5. 「限界」「limitation」を検索する
    主張の有効範囲が分かる
これで 10 分 この 5 回の検索だけで、Gap・目的・結果・解釈・限界が揃う。 概要の 6 要素とほぼ同じ情報が、本文から直接取れたことになる。
ただし、これは通読の代わりにはならない 骨格を先に取るための技術である。精読するなら、結局は全部読む（トピック 03）。

このトピックのまとめSummary

定型表現は、論文という文書形式が読者に用意した道しるべである。

  • 論文は定型的な表現で書かれている
  • 表現からその文の役割が分かる
  • 「しかし」「However」が最強の手がかり
  • セクション別の定型表現を覚える
  • 主張の強さは語尾・助動詞に表れる
  • 解釈を事実に格上げして引用しない
  • 検索機能で骨格を先に取る
  • 定型表現は、自分が書くときにも使える
書く側に回ったとき ここで覚えた表現は、そのまま自分の卒論で使える。 論文を読むことは、論文の書き方を学ぶことでもある。
