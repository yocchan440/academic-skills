関連研究の読み方

他人が作った分野の地図を、ただで手に入れる

  • 関連研究の章から分野の見取り図を得られる
  • 著者が主張する「差分」を正確に受け取れる
  • 関連研究の記述を鵜呑みにせず検証できる

操作：← → / Space でページ送り　O キーでスライド一覧

関連研究の章は「分野の地図」であるA free map

著者が何十本も読んで整理した結果が、数ページにまとまっている。使わない手はない。

ここから得られるもの
  • 分類の軸：この分野の研究はどう分けられるか
  • 主要文献のリスト：次に読むべき論文の候補
  • 各手法の限界：何ができて何ができないか
  • 用語：この分野で実際に使われている呼び名
  • 比較表：一目で分かる整理
サーベイ論文があれば最優先 サーベイ／SoK 論文は、関連研究の章だけでできた論文である。 分野に入るときは、まずサーベイを 1 本探す（トピック 15）。
読む順序
  1. 節の見出しだけを先に見る → 分類の軸が分かる
  2. 比較表があれば先に見る → 全体像が一気に入る
  3. 最後の節（本研究の位置づけ）を読む → 著者の主張する差分
  4. 必要な節だけ本文に戻る
頭から全部読まない 関連研究の章は、個別の研究紹介が並んでいるだけのことも多い。 自分に関係のある研究だけを拾えばよい。

2.5 本研究の位置づけ

この見出しを見た時点で、「この分野は入力データの種類で分けられている」と分かる。 これだけで、自分の研究がどこに属するかを考え始められる。

よく使われる分類の軸
  • アプローチ別：ルールベース／機械学習／深層学習
  • 入力データ別：URL／HTML／画像／通信ログ
  • 適用場所別：クライアント／サーバ／ネットワーク境界
  • 時系列：初期 → 発展 → 現在の主流
  • 前提別：教師あり／半教師あり／ゼロデイ対応
  • 攻撃者モデル別：受動的／能動的／適応的（セキュリティ分野）
自分でも同じ軸で整理する 読んだ論文を、その分野で使われている軸で並べ直す。 自分の研究の位置が見えてくる。

「本研究の位置づけ」節を読むPositioning

関連研究の章は、この節に向かって書かれている。ここが章の結論である。

2.5　本研究の位置づけ

　分類表 1 に示したとおり、フィッシングサイト検知の研究は、入力として用いる情報の種類によって大きく 3 つに分けられる。限界URL 文字列のみを用いる手法 [3][4] は高速に判定できる一方、攻撃者が URL を短縮した場合に判別性能が低下する。視覚的類似性を用いる手法 [7] は URL に依存しないが、画像処理に要する時間が大きい。

　差分本研究は、この両者の中間に位置づけられる。すなわち、HTML を取得する点では [7] と同様に URL 文字列への依存を断ち切りつつ、画像処理を伴わない軽量な特徴量を用いることで、[3][4] に近い処理速度を維持することを狙う。新規性また、短縮 URL を含む検体に限定した性能評価は、著者の知る限り報告されていない。

ここから取り出す 3 つ ① どの研究群と比較しているか　② 何が同じで、何が違うと主張しているか　③ 何を新規性として挙げているか

鵜呑みにしないVerify the claims

関連研究の記述は、著者というフィルタを通った要約である。

関連研究の章の記述読者がすべきこと
「[3] は〜という手法である」重要な文献なら原典を読む。要約は簡略化されている
「[3] は〜という限界がある」本当にそう書いてあるか。著者の解釈が入っている可能性
「著者の知る限り報告されていない」自分で検索する。その後に出た研究もある
言及されていない既知手法がある「言及がない」という事実のみを記録。理由は推理しない
比較表の ○×基準の定義を確認。定義がなければ参考程度に扱う
引用されている数値原典で条件を確認。孫引きしない
孫引きをしない この論文が [3] を引いているからといって、あなたが [3] を引用してよいわけではない。 引用するなら原典を読む。読まずに引用すると、内容が違っていて指摘される。

このトピックのまとめSummary

関連研究の章は、読む側にとっていちばん費用対効果の高い章である。

  • 他人が作った分野の地図として使う
  • 節の見出しから分類の軸を読み取る
  • 比較表と位置づけの節を先に読む
  • 頭から全部読まない
  • 比較表の○×の基準とF 値の測定条件を確認する
  • 著者の要約はフィルタを通っている
  • 重要な文献は原典を読む
  • 孫引きしない
自分の研究に使う 関連研究の章を読みながら、「自分の研究はこの地図のどこに置かれるか」を考える。 置き場所が見つからなければ、それは新規性かもしれないし、地図がまだ見えていないだけかもしれない。
