ACADEMIC SKILLS読む・書く・発表する

情報系の学生が研究に取り組むための教材です。 先行研究を読み、自分の成果を論文に書き、それを人前で発表する — この 3 つは、同じ「型」を別の角度から使う技能です。 どれも例示とサンプルを多く収録しているので、自分の原稿や発表と見比べながら使ってください。

3 つの教材

それぞれ独立して使えます。必要なものから読んでください。

STEP 1 ／ INPUT 論文の読み方 HOW TO READ PAPERS 推理せず、書いてあることを書いてあるとおりに読む。 IMRAD の構造と定型表現を手がかりに、限られた時間で必要な情報を取り出します。 情報セキュリティ分野に特有の読み方も扱います。
  • 大原則・IMRAD・どこから読むか
  • セクションごとの読み方（概要〜結論）
  • 定型表現・英語論文・脅威モデル
  • 批判的に読む・文献を辿る・AI ツール
全 16 トピック ＋ 定型表現の一覧 ＋ 精読ワークシート STEP 2 ／ OUTPUT 卒業論文の書き方 HOW TO WRITE A THESIS 「作文」でも「レポート」でもない文章を書く。 IMRAD の型、章ごとの書き方、日本語表記の作法、図表と引用のルールまで。 配布テンプレートを使った Overleaf / LaTeX の使い方も収録しています。
  • 大原則・構成・章ごとの書き方
  • 日本語表記・図表・引用と参考文献
  • 研究倫理と生成 AI・謝辞
  • Overleaf と LaTeX・執筆の進め方
全 16 トピック ＋ 執筆ガイドライン ＋ 提出前チェックリスト STEP 3 ／ DELIVER 卒研発表の仕方 HOW TO PRESENT 短い時間で、専門外の聴衆に成果を伝えきる。 聴衆が「？」と思わないように進めること、時間の無駄をなくすことに力点を置いています。 スライドの作り方から当日の振る舞いまで。

3 つはつながっている

同じ IMRAD という型を、読む側・書く側・話す側から使います。片方を学ぶと、もう片方が楽になります。

読む先行研究から Gap を見つける
→
書くその Gap を埋めた成果をまとめる
→
発表する8 分で聴衆に伝える
読む ↔ 書く

論文を読むときに探す 「しかし〜は明らかになっていない」の一文は、 自分が書くときに最も重要な一文でもあります。 定型表現は、読むための手がかりであり、書くための道具でもあります。

書く ↔ 発表する

発表の構成は、論文の構成（IMRAD）をそのまま圧縮したものです。 論文が書けていれば発表は作れますし、 発表で答えられない質問は、論文にも書けていないということです。

発表する ↔ 読む

聴衆が「？」と思ったら話が届かないのと同じで、 読者が「？」と思ったら論文も読まれません。 相手に負担をかけないという一点で、3 つは共通しています。

この教材について

読みやすさへの配慮
  • ユニバーサルデザインフォント（BIZ UD ゴシック／BIZ UD 明朝）を使用しています。 端末に無い場合は、OS 同梱の UD フォントや游書体で代替されます。
  • カラーユニバーサルデザインに配慮し、配色は Okabe–Ito の推奨 8 色を基準にしています。
  • 色だけで意味を区別せず、記号・ラベル・線種を必ず併用しています。 グレースケールで印刷しても内容が判別できます。
  • ライトテーマ固定。文字と背景のコントラストを確保しています。
操作方法
説明資料
HTML スライドです。ブラウザで開くだけで動作します
ページ送り
← → キー、Space、PageUp / PageDown、画面左右のボタン
スライド一覧
O キー、または右上の「スライド一覧」ボタン
特定のスライドを共有
URL 末尾の #5 がスライド番号です
印刷・PDF 化
右上の「印刷」ボタン。全スライドが 1 枚 1 ページで出力されます

インターネット接続は不要です（Web フォントの取得にのみ使用します）。
